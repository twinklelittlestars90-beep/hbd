# Happy Birthday, Kakak! ♡

Website ucapan ulang tahun berbasis React + Vite.

## Menjalankan project
1. Pastikan Node.js sudah terpasang.
2. Buka folder project di VS Code.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka alamat lokal yang muncul di terminal.

Foto referensi ada di `public/images/postcard-memory.jpg`. Untuk mengganti foto, ganti file tersebut dengan gambar lain dan pertahankan nama file yang sama.
